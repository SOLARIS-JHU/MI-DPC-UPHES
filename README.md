# Mixed-Integer Nonlinear Differentiable Predictive Control for Underground Pumped Hydro Energy Storage

Companion code for the paper "Mixed-Integer Nonlinear Differentiable Predictive Control for Underground Pumped Hydro Energy Storage Systems" (submitted to IEEE CDC 2026) by Honghui Zheng, Ján Boldocký, Yury Dvorkin, and Ján Drgoňa.

MI-DPC trains a Transformer policy that maps an initial hydraulic state and a 24-hour day-ahead price trajectory directly to hourly mode decisions (pump, idle, turbine) and continuous power setpoints. Training is self-supervised: gradients of the expected ex-post profit flow through a differentiable UPHES simulator and a Gumbel-Softmax straight-through estimator, so no pre-solved optimal schedules are needed. On 19 held-out benchmark days, MI-DPC reaches ex-post profit within 1.6% of a piecewise mixed-integer quadratic programming baseline while scheduling a full day in 4.9 ms, five orders of magnitude faster.

| Method | Profit (EUR/day) | Training time | Inference time |
|---|---|---|---|
| MIQP-GL | 1,997 | - | 1.91 s |
| MIQP-PW | 2,530 | - | 918.89 s |
| **MI-DPC (47 seeds)** | **2,489 ± 71** | **161 s** | **4.9 ms** |

## Repository layout

| Path | Contents |
|---|---|
| `DPC/` | MI-DPC implementation: differentiable simulator, Gumbel-Softmax STE, policy architectures, training harness (see `DPC/README.md`) |
| `DPC/experiments/` | Training and ablation tooling |
| `DPC/visualize/` | Scripts that generate the paper figures |
| `DPC/outputs/benchmark_suite/` | Summary CSVs and reports for the 47-seed ablation study backing the paper's numbers |
| `MIQP/` | MIQP-GL (global linearization) and MIQP-PW (piecewise SOS2) Gurobi baselines |
| `Data/` | Belgian Elia day-ahead prices (2024), unit performance curve data, plant portfolio |
| `figs/` | Paper figures generated by this repository |
| `tests/` | Pytest suite |
| `preprocessing.py`, `preprocess.pkl` | UPC surface fitting and preprocessed system parameters |

## Installation

```bash
conda create -n midpc python=3.11
conda activate midpc
pip install -r requirements.txt
```

The MIQP baselines additionally require a [Gurobi license](https://www.gurobi.com/academia/academic-program-and-licenses/). The paper used PyTorch 2.9.1 (CUDA 13.0), NeuroMANCER 1.5.6, and Gurobi 13.0.0.

## Reproducing the paper

All commands run from the repository root.

**Table I, MI-DPC:** train the winning configuration (Transformer, warmup-cosine LR, two-stage temperature annealing; frozen as the defaults) and evaluate on the 19 held-out benchmark days.

```bash
python -m DPC.experiments.benchmark_tuner
```

**Table I, MIQP baselines:**

```bash
python MIQP/MIQP_linear/MIQP_global_linear.py     # MIQP-GL
python MIQP/MIQP_piecewise/MIQP_piecewise.py      # MIQP-PW
```

**Ablation study (Fig. 5):** `generate_ablation_commands` prints a runnable bash script to stdout with one training command per ablation axis (architecture, temperature schedule, simulator); redirect it to a file, execute the file, then summarize the resulting run directories and plot. The paper aggregates seeds 0 through 46; pass the seed list you want via `--seeds`. The committed `DPC/outputs/benchmark_suite/ABLATION_47SEED_RUNS.csv` already contains the full 47-seed results, so `fig_ablation_violins` reproduces the paper figure without retraining.

```bash
python -m DPC.experiments.generate_ablation_commands --seeds 0,1,2,3,4 > ablation_commands.sh
bash ablation_commands.sh
python -m DPC.experiments.ablation_summary DPC/outputs/benchmark_suite/abl_* --aggregate
python -m DPC.visualize.fig_ablation_violins
```

**Standalone figures (no training required):**

```bash
python -m DPC.visualize.fig_gumbel_simplex   # Fig. 2: Gumbel-Softmax simplex samples
python -m DPC.visualize.fig_ste_clamp        # Fig. 3: standard vs straight-through clamp
```

**Experiment-driven figures** (`fig_schedule_evolution`, `fig_training_diagnostics`) consume run outputs under `DPC/outputs/benchmark_suite/`, so run training first. The committed summary CSVs in that directory let you verify the paper's numbers without retraining.
